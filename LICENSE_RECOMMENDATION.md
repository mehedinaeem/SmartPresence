# License decision required

No LICENSE file was present during this audit. No license has been assigned by this cleanup. The repository owner must choose and document terms before inviting reuse.

Options to review:

- [MIT](https://choosealicense.com/licenses/mit/): a short permissive code license with attribution and warranty disclaimer.
- [Apache-2.0](https://choosealicense.com/licenses/apache-2.0/): permissive code licensing with explicit patent-related provisions and notices.
- Research-only/custom terms: may fit a restricted collaboration, but restrict reuse and are not equivalent to a standard open-source license; have proposed terms reviewed.

Data, participant images, model weights and third-party dependencies can require separate permissions or terms. A code license cannot substitute for participant consent. Review upstream model/library terms and your institution's requirements before choosing. These are options for a decision, not a license grant.
