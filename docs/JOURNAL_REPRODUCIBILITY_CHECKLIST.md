# Journal reproducibility checklist

Complete this for the exact submitted run; repository tooling alone does not establish these items.

- [ ] Dataset version frozen
- [ ] Dataset hash recorded
- [ ] Participant count recorded
- [ ] Covered/uncovered split recorded
- [ ] Training configuration frozen
- [ ] Random seed recorded
- [ ] FaceNet version recorded
- [ ] SVM configuration recorded
- [ ] Test split recorded
- [ ] Metrics saved
- [ ] Unknown threshold documented
- [ ] Tracking configuration documented
- [ ] Hardware/software environment documented
- [ ] Static fingerprint simulation clearly labeled
- [ ] No private biometric data accidentally published
- [ ] Figures generated from saved experiment outputs
- [ ] Paper numbers match repository numbers
- [ ] Git commit recorded before submission
- [ ] Historical 5,737-crop and 6,901-embedding snapshots distinguished
- [ ] Split independence and near-duplicate leakage reviewed
- [ ] Consent/release permissions confirmed; no undocumented ethics claims
- [ ] Code license and separate data/model terms chosen
- [ ] Citation authorship confirmed
- [ ] Covered-track association and hardware integration limitations disclosed
